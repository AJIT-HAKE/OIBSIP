# Retail Sales Exploratory Data Analysis (EDA)

## Project Overview
This project analyzes retail sales data using Python to identify sales trends, customer patterns, product category performance, and numerical relationships.

## Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Dataset
The dataset contains 1,000 transactions and includes transaction dates, customer details, product categories, quantities, unit prices, and total amounts.

## Analysis Performed
- Data inspection and quality checks
- Descriptive statistics
- Monthly sales trends
- Product category sales analysis
- Customer gender and age-group analysis
- Correlation heatmap
- Top 10 sales transactions

## Key Findings
- Total sales revenue: 456,000
- Highest-revenue category: Electronics
- Highest-revenue age group: 46–55
- Highest-sales month: May 2023

## Project Files
- `Retail_Sales_EDA.ipynb`: Analysis notebook
- `retail_sales_dataset.csv`: Dataset
